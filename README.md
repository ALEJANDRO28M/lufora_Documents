# LUFORA · Documentación técnica

Documentación del proyecto LUFORA S.A.S. Son páginas HTML sin dependencias:
se abren con doble clic o se publican como sitio con GitHub Pages.

| Página | Contenido |
|---|---|
| `index.html` | **Manual del backend.** Qué hace cada archivo, por qué existe y qué se rompería sin él. Incluye la receta para construir el módulo de inventario. |
| `plano.html` | **Plano y fases.** Arquitectura, recorrido de una petición y las 6 fases del proyecto con su estado. |
| `hexagonal.html` | **Mapa hexagonal.** Cómo se reorganizaría el proyecto en puertos y adaptadores, si algún día conviene. |

## Publicar como sitio web

En este repositorio: **Settings → Pages → Source: Deploy from a branch →
Branch: `main`, carpeta `/ (root)` → Save.**

En un par de minutos queda en:
`https://alejandro28m.github.io/lufora_Documents/`

> **Importante:** GitHub Pages no publica desde repositorios privados en el plan
> Free. Si el repo es privado y la opción aparece bloqueada, hay que hacerlo
> público o pasar a GitHub Pro. Ten en cuenta que el sitio publicado es
> **público** en ambos casos: la privacidad del repositorio no hace privado el sitio.

## Ver sin publicar

No hace falta GitHub Pages: abre `index.html` directamente en el navegador.
Funciona igual, solo que sin URL para compartir.
